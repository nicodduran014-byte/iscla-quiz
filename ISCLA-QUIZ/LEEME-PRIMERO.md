# Empezá acá para utilizar la “demo” servidor local · ISCLA QUIZ

1. Extraé todo el ZIP en una carpeta normal. No abras el archivo desde el Explorador del ZIP.
2. Hacé doble clic en `ABRIR-ISCLA-QUIZ.cmd`. La primera vez descarga una copia portátil de Python desde Python.org, verifica la descarga y la guarda en esa carpeta. No instala Python ni requiere permisos de administrador. Para esa primera apertura hace falta Internet.
3. Cuando la consola pida el código de registro docente, pegá el que decidiste usar y presioná Enter. El código no aparece mientras se escribe. Volvé a ingresar el mismo al iniciar el servidor en otra ocasión.
4. Abrí [http://localhost:8000](http://localhost:8000) y andá a **Panel docente → Crear cuenta docente**. Registrate con tu correo, tu contraseña personal y el mismo código. Después, el código solo se usa para registrar otras cuentas.

**Durante una partida en el aula:** dejá la consola abierta, conectá la PC y los celulares a la misma red Wi-Fi y proyectá el QR. El panel y el servidor necesitan estar activos en la computadora docente. Los celulares no instalan nada.

- Si actualizás desde la versión anterior, copiá la carpeta `datos` cuando el servidor esté apagado para conservar cuentas, preguntas y partidas. Guardá esa carpeta fuera de repositorios públicos.
- Si la primera descarga falla, revisá si la computadora tiene Internet y puede acceder a `www.python.org`. Si el archivo de inicio ya existe, usá siempre `ABRIR-ISCLA-QUIZ.cmd` para este modo.
- El iniciador original sigue incluido para equipos que ya tienen Python. Consultá `README.md` para otros detalles del proyecto.

El lanzador utiliza la distribución oficial [Python 3.13.17 para Windows](https://www.python.org/downloads/release/python-31317/) sin instalarla en el sistema. El código institucional no está guardado dentro del ZIP.
